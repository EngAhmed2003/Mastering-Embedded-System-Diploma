# 🚀 Mastering Embedded Systems Diploma - Learn In Depth

Welcome to my repository for the **Mastering Embedded Systems Diploma** provided by **Learn In Depth**. This repository serves as a complete archive of my learning journey, source code, drivers, embedded projects, and assignments.

---

## 📌 Overview

This diploma covers end-to-end Embedded Systems development—from bare-metal programming and driver development to Advanced Microcontroller Architectures, Real-Time Operating Systems (RTOS), and Automotive Protocols.

---

## 🛠️ Diploma Content & Structure

### 🔹 Module 1: C Programming & Data Structures
* **C Basics & Advanced Concepts** (Pointers, Memory Layout, Data Types, Modifiers)
* **Data Structures** (Queue, Circular Buffer, Stack, Linked Lists)
* **Algorithms & Problem Solving**

### 🔹 Module 2: Tooling & Embedded C
* Compilation Process & Toolchains (GCC, Makefiles)
* Embedded C Concepts (Volatile, Const, Startup Code, Linker Scripts)

### 🔹 Module 3: Microcontroller Architecture & Interfacing
* **Architectures:** ARM Cortex-M (STM32), ATmega32
* **Peripherals & Drivers:** GPIO, EXTI, USART, SPI, I2C, Timers, ADC
* **Interfacing:** LCD, Keypad, Seven-Segment, Motors

### 🔹 Module 4: System Architecture & Data Communication
* **Automotive Communication Protocols:** CAN Protocol, LIN
* **Layered Software Architecture (AUTOSAR Concepts)**

### 🔹 Module 5: Real-Time Operating Systems (RTOS)
* FreeRTOS Fundamentals
* Task Management, Scheduling, Semaphores, Mutexes, Queues
