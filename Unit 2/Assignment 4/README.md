# Unit 2 - Assignment 4

This folder contains the C programming exercises from **Unit 2 - Assignment 4** of the Mastering Embedded Systems Diploma.

## 📌 Exercises

| Exercise | Description |
|---|---|
| EX_1 | Print prime numbers between two intervals using a user-defined function |
| EX_2 | Calculate the factorial of a number using recursion |
| EX_3 | Reverse a sentence using recursion |
| EX_4 | Calculate the power of a number using recursion |

## ▶️ Sample Input and Output

### EX_1 — Prime Numbers Between Two Intervals

```text
Enter two number(intervals): 10 30
Prime numbers between 10 and 30: 11 13 17 19 23 29
```

The program prints prime numbers strictly between the two entered interval limits.

### EX_2 — Factorial Using Recursion

```text
Enter a positive integer number: 6
720
```

### EX_3 — Reverse a Sentence Using Recursion

```text
Enter a sentence: margorp emosewa
awesome program
```

### EX_4 — Power Using Recursion

```text
Enter base number: 3
Enter power number: 3
3 ^ 3 = 27
```

The exponent must be a positive integer. If the entered exponent is zero or negative, the program prints an error message.
