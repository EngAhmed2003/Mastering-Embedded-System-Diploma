# Unit 2 - Midterm Codes

This folder contains **10 C programming solutions** for the Unit 2 midterm practice questions from the Mastering Embedded Systems Diploma.

## 📌 Exercises

| Exercise | Description |
|---|---|
| EX_1 | Calculate the sum of all digits in an integer using recursion |
| EX_2 | Calculate the square root of a non-negative integer using an iterative method |
| EX_3 | Print prime numbers between two input numbers |
| EX_4 | Reverse the digits of an integer using recursion |
| EX_5 | Convert an integer to binary digits and count the number of ones |
| EX_6 | Find the unique number in an array using one loop and XOR |
| EX_7 | Calculate the sum of numbers from 1 to 100 using recursion without loops |
| EX_8 | Print the elements of an array in reverse order using recursion |
| EX_9 | Reverse the order of words in a string |
| EX_10 | Find the maximum number of consecutive ones between two zeros in a binary representation |

## ▶️ Sample Input and Output

### EX_1 — Sum of Digits

```text
Input: 123
Output: 6

Input: 4565
Output: 20
```

### EX_2 — Square Root

```text
Input: 4
Output: 2.000000
```

### EX_3 — Prime Numbers Between Two Numbers

```text
Input: 1 20
Output: 2 3 5 7 11 13 17 19
```

### EX_4 — Reverse Digits

```text
Input: 2457
Output: 7542

Input: 1057
Output: 7501
```

### EX_5 — Count Ones in Binary

```text
Input: 5
Output: binary of 5 is 101 so has 2 ones

Input: 15
Output: binary of 15 is 1111 so has 4 ones
```

### EX_6 — Find the Unique Number

```text
Input: {4, 2, 5, 2, 5, 7, 4}
Output: 7

Input: {4, 2, 4}
Output: 2
```

The solution uses XOR and assumes that every repeated value occurs an even number of times, while one value occurs once.

### EX_7 — Sum from 1 to 100 Without a Loop

```text
Output: 5050
```

### EX_8 — Reverse Array Elements

```text
Input: {1, 2, 3, 4, 5}
Output: 5 4 3 2 1
```

### EX_9 — Reverse Words in a String

```text
Input: mohamed gamal
Output: gamal mohamed
```

### EX_10 — Maximum Ones Between Two Zeros

```text
Input: 14 (01110)
Output: 3

Input: 110 (01101110)
Output: 3
```

The program displays the 32-bit representation before printing the maximum count.
