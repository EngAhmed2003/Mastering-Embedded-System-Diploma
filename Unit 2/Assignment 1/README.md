# Unit 2 - Assignment 1

This folder contains the C programming exercises from **Unit 2 - Assignment 1** of the Mastering Embedded Systems Diploma.

## 📌 Exercises

| Exercise | Description |
|---|---|
| EX_1 | Print a sentence |
| EX_2 | Print an integer entered by the user |
| EX_3 | Add two integers |
| EX_4 | Multiply two floating-point numbers |
| EX_5 | Find the ASCII value of a character |
| EX_6 | Swap two numbers using a temporary variable |
| EX_7 | Swap two numbers without using a temporary variable |

## ▶️ Sample Input and Output

### EX_1 — Print a Sentence

```text
!!!Hello World!!!
```

### EX_2 — Print an Integer

```text
Enter an integer: 25
You entered: 25
```

### EX_3 — Add Two Integers

```text
Enter two integers: 12 8
Sum: 20
```

### EX_4 — Multiply Two Floating-Point Numbers

```text
Enter two numbers: 2.5 4
Product: 10.000000
```

### EX_5 — Find the ASCII Value of a Character

```text
Enter a character: A
ASCII value: 65
```

### EX_6 — Swap Two Numbers Using a Temporary Variable

```text
Enter a value of A: 10
Enter a value of B: 20
After swapping, value of a: 20.00
After swapping, value of b: 10.00
```

### EX_7 — Swap Two Numbers Without a Temporary Variable

```text
Enter a value of A: 5
Enter a value of B: 9
After swapping, value of a: 9.00
After swapping, value of b: 5.00
```
