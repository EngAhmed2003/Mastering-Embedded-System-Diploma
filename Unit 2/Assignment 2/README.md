# Unit 2 - Assignment 2

This folder contains the C programming exercises from **Unit 2 - Assignment 2** of the Mastering Embedded Systems Diploma.

## 📌 Exercises

| Exercise | Description |
|---|---|
| EX_1 | Check whether a number is even or odd |
| EX_2 | Check whether an alphabet is a vowel or consonant |
| EX_3 | Find the largest number among three numbers |
| EX_4 | Check whether a number is positive, negative, or zero |
| EX_5 | Check whether a character is an alphabet |
| EX_6 | Calculate the sum of natural numbers |
| EX_7 | Calculate the factorial of a number |
| EX_8 | Implement a simple calculator using switch-case |

## ▶️ Sample Input and Output

### EX_1 — Even or Odd

The program checks two integers.

```text
Enter an integer you want to check: 6
6 is even
Enter an integer you want to check: 7
7 is odd
```

### EX_2 — Vowel or Consonant

The program checks two characters. This example uses letters handled correctly by the current program.

```text
Enter an alphabet to check: e
e is vowel
Enter an alphabet to check: b
b is consonant
```

### EX_3 — Largest of Three Numbers

```text
Enter three different numbers: 2 9 4
Largest number is: 9.00
```

### EX_4 — Positive, Negative, or Zero

The program checks two numbers.

```text
Enter a number: 3.5
3.50 is Positive
Enter a number: 0
You entered Zero
```

### EX_5 — Check Whether a Character Is an Alphabet

The program checks two characters.

```text
Enter an alphabet: G
G is an alphabet
Enter an alphabet: 7
7 is not an alphabet
```

### EX_6 — Sum of Natural Numbers

```text
Enter an integer: 5
Sum: 15
```

### EX_7 — Factorial

The program asks for an integer twice.

```text
Enter an integer: 5
Factorial = 120
Enter an integer: 0
Factorial = 1
```

### EX_8 — Simple Calculator

Example using multiplication:

```text
Enter operator ( + , - , *, / ): *
Enter two operands: 4 5
4.00 * 5.00 = 20.00
```
