# Unit 2 - Assignment 5

This folder contains the C programming exercises from **Unit 2 - Assignment 5** of the Mastering Embedded Systems Diploma.

## 📌 Exercises

| Exercise | Description |
|---|---|
| EX_1 | Store and display a student's name, roll number, and marks using a structure |
| EX_2 | Add two distances in feet and inches using structures |
| EX_3 | Add two complex numbers by passing structures to a function |
| EX_4 | Store and display information for 10 students using an array of structures |
| EX_5 | Calculate the area of a circle using macros |

## ▶️ Sample Input and Output

### EX_1 — Student Information Using a Structure

```text
Enter a name: Adele
Enter roll_number: 21
Enter marks: 334.5

Name: Adele
Roll: 21
Marks: 334.50
```

### EX_2 — Add Two Distances

```text
Enter information for 1st distance:
Enter feet: 12
Enter inch: 3.45

Enter information for 2nd distance:
Enter feet: 12
Enter inch: 9.2

sum of distance = 25'-0.6"
```

The program adds the feet and inches separately, then carries every 12 inches into one additional foot.

### EX_3 — Add Two Complex Numbers by Passing Structures to a Function

```text
Enter information for 1st complex number:
Enter reel and imaginary respectively: 2.3 4.5

Enter information for 2nd complex number:
Enter reel and imaginary respectively: 3.4 5

sum = 5.7+9.5i
```

The two complex-number structures are passed to a function, which returns their sum as a structure.

### EX_4 — Student Information Using an Array of Structures

The program accepts the roll number, name, and marks for 10 students, stores them in an array of structures, and then displays the stored information.

### EX_5 — Area of a Circle Using Macros

```text
Enter the radius: 3
Area = 28.29
```
